# DdChordsPwa

SPA / PWA client for songs with chords. See the [Deployed Site] for the CI-built app.

There is no backend: the song dataset lives in `src/assets/dd-chords/`, and on load the client
syncs it into IndexedDB. Details in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Client Tech

### UI Framework

[Angular] v22, standalone components, zoneless change detection.

#### UI Experience

No additional UI frameworks.

#### Localization

The client doesn't contain any localization at the moment.

### Testing

[Jest] is used for unit testing (matching-snapshot testing for components): `pnpm test`.

### CI

Travis ([.travis.yml](.travis.yml)) runs `pnpm test && pnpm build` on `main` and deploys to
[Firebase] hosting. Local deploys are still possible with `firebase-tools`:

```
npm install -g firebase-tools
pnpm build
firebase login
firebase deploy
```

## Local Dev

pnpm 11.8.0 is activated through Corepack. Enable it once, then activate the pinned version:

```
corepack enable
corepack prepare pnpm@11.8.0 --activate
```

Use `pnpm run build:watch` to watch-build the client in `dist/*`, concurrently run `pnpm start` to
serve with `express`.

### HTTPS

`pnpm start` serves over HTTPS, so create `key.pem` and `cert.pem` with (in GitBash)
`openssl req -newkey rsa:2048 -new -nodes -x509 -days 3650 -keyout key.pem -out cert.pem`.
You will be prompted with a few questions after entering the command.
Use `127.0.0.1` as value for `Common name` to later install the certificate in your OS's root
certificate store or browser.
This generates a cert-key pair and it will be valid for 3650 days (about 10 years).

### Chords index

`src/assets/dd-chords/dd-chords.json` (the md5 hash index of the `.txt` files) is generated by
`pnpm run generate-chords-index`, which `prebuild` runs. It is gitignored — don't hand-edit it.

### Notes on pnpm

- `@angular/cli` stays a dev dependency; run `ng` through `pnpm exec ng` or `pnpm run`.
- After `pnpm install --frozen-lockfile`, rebuild the esbuild binary: `pnpm rebuild esbuild`.
- `strictPeerDependencies` is on. If a peer-relationship error aborts an install, record the
  resolved version in `pnpm-workspace.yaml` (`overrides`) rather than turning the setting off.
- Corepack (`packageManager`) activates pnpm 11.8.0.
