# dd-chords-pwa

Single-page PWA serving song lyrics with chords. Dataset as static assets, browser storage in
IndexedDB, Firebase hosting, Travis CI. There is no backend.

## Tech stack

- Angular 22 (standalone components, zoneless, OnPush), built with `@angular/build`
- RxJS, TypeScript strict, Jest + ng-mocks, Prettier, ESLint
- IndexedDB, Firebase Hosting, Service Worker (ngneat `@angular-toolkit/server`)

## Build

```
pnpm run build:watch
```

## Run

```
pnpm start
```

The app is then available at https://localhost:4200

### Deploy

- Run `pnpm build` and deploy `dist` to Firebase

Requirements:

- Node 20 LTS or newer (matches package.json `engines`)
- Firebase CLI: `npm install -g firebase-tools`
- Configure the Firebase project with `firebase init`

## Local Dev

pnpm is activated through Corepack. Enable it once, then activate the pinned version:

```
corepack enable
corepack prepare pnpm@11.8.0 --activate
```

Use `pnpm run build:watch` to watch-build the client in `dist/*`, concurrently run `pnpm start` to
serve with `express`.

### HTTPS

`pnpm start` serves over HTTPS, so create `key.pem` and `cert.pem` with (in GitBash)
`openssl req -newkey rsa:2048 -new -nodes -x509 -days 3650 -keyout key.pem -out cert.pem`.
Use `127.0.0.1` as the `Common name` so the certificate can be installed in your OS's root store
or the browser's. Both files are gitignored — never commit them.

### Chords index

`src/assets/dd-chords/dd-chords.json` (the md5 hash index of the `.txt` files) is generated by
`pnpm run generate-chords-index`, which `prebuild` runs. It is gitignored — don't hand-edit it.
